# CLAUDE.md – GigFlow

## Project Overview
GigFlow is a simple event booking tracker for artists and their managers. It helps users organize booking requests, track upcoming performances, and keep an overview of potential earnings.

## Tech Stack
- HTML for the page structure
- CSS for styling
- Vanilla JavaScript for functionality
- localStorage to save user data
- No frameworks, libraries, or build tools

## How to Run
- Open `index.html` in a web browser.
- No installation, server, or build process is required.

## Project Conventions
1. Keep the project simple. Use separate files for HTML, CSS, and JavaScript.
2. The app should have a clean, modern design that works on both desktop and mobile.
3. All buttons and input fields must have clear labels so users understand what they do.
4. Display all prices in euros (€) with two decimal places.
5. Display dates in DD.MM.YYYY format.
6. Use consistent colors for booking statuses throughout the app.
7. User data must remain available after refreshing or reopening the page.

## Prohibitions
- Do not use external frameworks such as React, Vue, or Angular.
- Do not use a database, backend, or external API.
- Do not add unnecessary dependencies or a build process.
